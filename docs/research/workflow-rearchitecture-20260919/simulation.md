## 5. Quantitative isolation and ensemble semantics

`WorldState` is a scenario distribution evolved from batched **model-elicited** commitments, not an observed economic/physical simulator. [decision_channel.py:173](/Users/rogerlin/Downloads/DeepResearchForecast/backend/app/services/decision_channel.py:173) asks a model to infer commitment/magnitude/confidence from a roster, incentives, a short action snippet and immutable initial base shares. [worldstate.py:81](/Users/rogerlin/Downloads/DeepResearchForecast/backend/app/services/worldstate.py:81) separates outcome power from activation influence. Missing outcome power remains neutral 1.0 with an explicit unknown flag in the roster ([decision_channel.py:399](/Users/rogerlin/Downloads/DeepResearchForecast/backend/app/services/decision_channel.py:399)); it is not permission, feasibility, or causal authority. The existing expected-failure characterization acknowledges that stronger quantitative ineligibility remains open ([test_architecture_characterization.py:153](/Users/rogerlin/Downloads/DeepResearchForecast/backend/tests/test_architecture_characterization.py:153)).

Keep the current default containment: `SIMULATION_FORECAST_EFFECT=diagnostic_only`, and unpromoted `validated_update` does not activate numerical updates in the post-hoc path ([decision_channel.py:724](/Users/rogerlin/Downloads/DeepResearchForecast/backend/app/services/decision_channel.py:724)).
